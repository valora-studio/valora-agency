# Сайт Valora — маркетинговое агентство

Второй сайт студии. Первый (`../site/`) продаёт «обёртку» (страница + лид-магнит + бот)
от самозанятого; этот — агентские услуги от ИП. Оформление то же, фирстиль S6.

## Сборка

Страницы генерируются, руками `*.html` не править.

```bash
PYTHONIOENCODING=utf-8 python build.py          # → 9 страниц рядом
PYTHONIOENCODING=utf-8 python shot.py           # рендеры 1440 в out/
PYTHONIOENCODING=utf-8 python shot.py 500       # под телефон
```

Реквизиты и контакты — `SITE` в начале `build.py`. Пока `ogrnip` пуст, `build.py`
выходит с кодом 1, а на страницах стоит заглушка «[ogrnip — не заполнено]».

## Что решено, а что предположено

- Прайс-листа нет (решение Андрея 2026-10-16): стоимость называется письменно до оплаты, оферта п. 3.1.
- Услуги — список направлений в `DIRECTIONS` / `SERVICES`, включая продакшн вертикального контента.
- ⚠ Режим налогообложения ИП **предположен как НПД** (`TAX` в `build.py`). Другой режим — поменять `TAX`.
- Страницы «Работы» нет (убрана по просьбе Андрея 2026-10-16).
- Условия старого продукта («возврат 20 000 ₽ за 90 дней», «10 % чистой прибыли») сюда не переносились.
- Рекламный бюджет платит заказчик площадкам напрямую, мы его не принимаем (оферта п. 2.5, 3.3).
- Адрес `SITE["base"]` — предполагаемый: репо `valora-studio/valora-agency`.
